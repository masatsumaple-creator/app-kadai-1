# 家計簿アプリ 要件定義書

## 1. 概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | 家計簿アプリ（app-kadai-1） |
| 目的 | 講座課題として、個人の収支を記録・集計できるWebアプリを開発する |
| 想定利用者 | 個人利用（単一ユーザー、ログイン機能なし） |
| 提出期限 | 未定（フェーズ分けして段階的に開発） |

## 2. 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | Vue.js 3 + Vite |
| バックエンド | Python + Flask |
| データベース | MySQL |
| ORM | SQLAlchemy |
| 通信方式 | REST API（JSON） |

個人利用かつ単一ユーザー想定のため、ユーザー登録・ログイン機能は実装しない。

## 3. 機能要件

個人利用目的のため全機能を実装対象とする。基本機能（F-01〜F-04）→拡張機能（F-05〜F-08）の順に開発する。

### 3.1 基本機能

#### F-01 収支データ管理（CRUD）
- 収支データを登録できる
  - 項目: 日付、種別（収入／支出）、金額、カテゴリ、メモ
- 登録済みデータを一覧表示できる（日付の新しい順などソート可能）
- 登録済みデータを編集・削除できる

#### F-02 カテゴリ管理
- カテゴリの追加・編集・削除ができる
- 初期カテゴリ（例: 食費・交通費・住居費・娯楽費・給与・その他）を用意する

#### F-03 集計表示
- 月単位で収入合計・支出合計・差額（収支）を表示する
- カテゴリ別の支出合計を表示する

### 3.2 拡張機能

#### F-04 グラフ表示
- カテゴリ別支出の円グラフ
- 月別収支推移の折れ線グラフ

#### F-05 予算管理
- カテゴリごとに月間予算を設定できる
- 予算に対する使用状況（進捗バーなど）を表示する

#### F-06 データ入出力
- 収支データをCSV形式でエクスポートできる
- CSVファイルをインポートして一括登録できる

#### F-07 検索・絞り込み
- 期間・カテゴリ・キーワード（メモ）で収支データを絞り込める

## 4. 非機能要件

| 分類 | 要件 |
|---|---|
| セキュリティ | SQLインジェクション対策としてORM経由でのみDB操作を行う。CSVインポート時は入力値を検証する |
| ユーザビリティ | PCブラウザでの利用を基本とし、レスポンシブ対応は任意とする |
| 保守性 | フロントエンド／バックエンドを分離し、REST APIで連携する構成とする |
| 動作環境 | モダンブラウザ（Chrome, Edge等）の最新版 |
| データ整合性 | 削除されたカテゴリに紐づく収支データの扱いを定義する（例: カテゴリ削除時は「未分類」に変更、または削除不可とする） |

## 5. データモデル（案）

単一ユーザー想定のため `user_id` は持たず、全データをアプリ内で共有する。

### 5.1 categories テーブル

| カラム名 | 型 | 制約 |
|---|---|---|
| id | INT | PK, AUTO_INCREMENT |
| name | VARCHAR(100) | NOT NULL |
| type | ENUM('income','expense') | NOT NULL |

### 5.2 transactions テーブル（収支データ）

| カラム名 | 型 | 制約 |
|---|---|---|
| id | INT | PK, AUTO_INCREMENT |
| category_id | INT | FK → categories.id |
| type | ENUM('income','expense') | NOT NULL |
| amount | DECIMAL(10,2) | NOT NULL |
| date | DATE | NOT NULL |
| memo | VARCHAR(255) | NULL許容 |
| created_at | DATETIME | NOT NULL |

### 5.3 budgets テーブル

| カラム名 | 型 | 制約 |
|---|---|---|
| id | INT | PK, AUTO_INCREMENT |
| category_id | INT | FK → categories.id, NOT NULL |
| year_month | VARCHAR(7) | NOT NULL（例: '2026-10'） |
| amount | DECIMAL(10,2) | NOT NULL |

## 6. 画面一覧（案）

| # | 画面名 | 概要 |
|---|---|---|
| 1 | 収支一覧画面 | 登録済みデータの一覧・編集・削除、新規登録フォーム、検索・絞り込み |
| 2 | カテゴリ管理画面 | カテゴリの追加・編集・削除 |
| 3 | 集計・レポート画面 | 月別集計、カテゴリ別集計、グラフ表示（円グラフ・折れ線グラフ） |
| 4 | 予算設定画面 | カテゴリ別の月間予算設定・進捗表示 |
| 5 | データ入出力画面（または一覧画面内の機能） | CSVエクスポート・インポート |

## 7. API一覧（概要・案）

| メソッド | パス | 概要 |
|---|---|---|
| GET | /api/transactions | 収支データ一覧取得（期間・カテゴリ・キーワードでの絞り込み対応） |
| POST | /api/transactions | 収支データ登録 |
| PUT | /api/transactions/:id | 収支データ更新 |
| DELETE | /api/transactions/:id | 収支データ削除 |
| GET | /api/transactions/export | CSVエクスポート |
| POST | /api/transactions/import | CSVインポート |
| GET | /api/categories | カテゴリ一覧取得 |
| POST | /api/categories | カテゴリ登録 |
| PUT | /api/categories/:id | カテゴリ更新 |
| DELETE | /api/categories/:id | カテゴリ削除 |
| GET | /api/summary?month=YYYY-MM | 月別・カテゴリ別集計取得（グラフ用データ含む） |
| GET | /api/budgets?month=YYYY-MM | 指定月の予算一覧・使用状況取得 |
| POST | /api/budgets | 予算登録 |
| PUT | /api/budgets/:id | 予算更新 |
| DELETE | /api/budgets/:id | 予算削除 |

## 9. 未決定事項・今後の検討課題

- カテゴリ削除時の既存データの扱い（「未分類」化 or 削除禁止）
- 複数通貨・多言語対応の有無（本課題では対応しない想定）
- デプロイ先（ローカル動作のみか、クラウドへの公開を行うか）
